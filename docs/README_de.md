## Übersicht

HMCL ist ein plattformübergreifender Open-Source-Minecraft-Launcher mit umfassender Unterstützung für Mod-Verwaltung, Spielanpassungen, ModLoader-Installation (Forge, NeoForge, Cleanroom, Fabric, Legacy Fabric, Quilt, LiteLoader und OptiFine), Modpack-Erstellung, UI-Anpassung und vieles mehr.

HMCL zeichnet sich durch seine vielseitige Plattformunabhängigkeit aus: Neben gängigen Betriebssystemen wie Windows, Linux, macOS und FreeBSD werden auch verschiedenste CPU-Architekturen unterstützt (darunter x86, ARM, RISC-V, MIPS und LoongArch). So lässt sich Minecraft nahtlos auf unterschiedlichsten Plattformen genießen.

Eine vollständige Übersicht der unterstützten Betriebssysteme und CPU-Architekturen ist in [dieser Tabelle](PLATFORM.md) zu finden.

## Mitwirken

HMCL ist ein communitybasiertes Open-Source-Projekt – Beiträge in Form von Code, Feedback oder Verbesserungsvorschlägen sind jederzeit herzlich willkommen!

Möglichkeiten zur Mitarbeit:

- **Fehler melden oder Funktionen vorschlagen**: Erstelle ein [neues Issue auf GitHub](https://github.com/HMCL-dev/HMCL/issues/new/choose).
- **Code beitragen**: Forke das Repository auf GitHub und reiche einen [Pull Request](https://github.com/HMCL-dev/HMCL/compare) ein.

Bitte lies vor deinem ersten Beitrag den [Leitfaden für Mitwirkende](./Contributing.md). Dort findest du unter anderem:

- [Kompilieren und Ausführen von HMCL aus dem Quellcode](./Contributing.md#build-hmcl)
- [Anpassen des Launcher-Verhaltens über Debug-Optionen](./Contributing.md#debug-options)
